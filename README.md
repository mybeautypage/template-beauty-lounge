# Beauty Lounge – Kunden-Template

Statisches Starter-Template für MyBeautyPage-Kundenwebsites.

Wird per Admin-Provisioning in das Kunden-GitHub-Repo kopiert und auf
`{slug}.mybeautypage.de` (gleicher Mittwald-Host) deployed.

Platzhalter-Inhalte („Studio Name“) werden durch den Website-Fragebogen
(Cursor Cloud Agent) ersetzt.
